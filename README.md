An example Helm chart to deploy the demo app from the book Kubernetes Up And Running.

[Kubernetes Up and Running](https://www.amazon.com/Kubernetes-Running-Dive-Future-Infrastructure/dp/1492046531)

[Demo app code](https://github.com/kubernetes-up-and-running)

Render the chart templates locally:

e.g.

`make template/dev`

Install or upgrade the chart:

e.g.

`make install/dev`
